    The instrument's own errors¶

    The tool's first published finding was about the tool. That case, and the ones that followed it, are why every result is screened against the instrument before it is attributed to a device.

    A measuring instrument can manufacture exactly the structure it is built to detect. These are the cases where this one did. Each was found, fixed and then held by a test, and each changed how results are read.

    1. The first finding was ours¶

    What was seen. On the first multi-element capture, the measured code offset carried a periodic error whose period was exactly the time the commanded delay took to cross one sample, matching the Doppler prediction to within 1 % on every satellite, at 0.16–0.42 samples. A null test on a synthetic signal showed nothing, so it was published as the generator's interpolator ripple.

    What it was. The correlator's replica placed chip edges by a truncated index, so it could not put an edge between samples. The fractional part of the code offset was silently discarded, and came back as a ±0.5-sample sawtooth at exactly that period. The null control missed it because the synthetic signal snapped its chip edges by the same rule: the fixture and the replica quantized together, and the error cancelled by construction. The control was sound for every failure except the one it was built to rule out.

    What changed.

    • The replica now applies the fractional delay exactly, as a band-limited phase ramp.
    • The synthetic fixtures place chips by a deliberately different model (integrate and dump in time, rather than a phase ramp in frequency), so agreement is evidence rather than a tautology.
    • The original finding was retracted as to attribution, not deleted. The measurement and the period relation were right; whose error it was was wrong.
    • tools/probes/probe_replica_placement.py pins the pointer to the truth and sweeps a whole sample of delay. Every number it prints should be zero. Run it before attributing a ripple at this period to any device.

    Re-run on the same capture, the ripple detector went from firing on 5 of 8 series to 0 of 32.

    2. A navigation data bit broke two estimators¶

    What was seen. On the same capture, some satellites showed single-epoch code excursions of tens of samples, and C/N0 read about 28 dB-Hz against a code scatter implying thirty times more signal.

    What it was. A 50 bps navigation bit inverts the prompt correlation. The carrier fit unwrapped the plain phase angle and could not tell a half-cycle data step from a real one. It was wrong by 5–9 Hz at every C/N0, which is about 0.79 samples (19 m) of code offset. The C/N0 estimator's coherent mean cancelled on the same bit, and read about 17 dB-Hz whatever the true value.

    What changed. The carrier is fitted on the doubled angle, which removes the ±1 modulation, and the bit is removed before power is estimated. On the capture, code error went from 10.4 to 0.08 samples on the worst satellite with no epochs rejected, and C/N0 read 50–54 dB-Hz. The cost is stated: below about 38 dB-Hz on a 1 ms epoch, the per-epoch bit decision gives out.

    3. The discriminator's gain was assumed, not measured¶

    What was seen. On Galileo E1B, refinement never settled: it overshot the null and kept oscillating around it.

    What it was. The early-late balance was converted to samples with the slope of an ideal triangle. The real slope is steeper by 2.1× on E1B (its BOC correlation peak is narrow) and 1.2× on L1 C/A. A gain of 2 is exactly where a correction stops shrinking the error and just flips its sign. Every E1B pointer had been sitting about 0.6 samples (15 m) off the null.

    What changed. Four probe taps around the early/late pair measure the slope on each series, and the measured slope is recorded with every code offset. Refinement takes four passes. Ratios, timings and attributions from earlier results stood; their magnitudes in samples shrank.

    4. An unmodelled pilot looked like a defect¶

    What was seen. On E1B, after a generator fix had removed a larger effect, the code offset took exactly two values, flipping every 4 ms epoch.

    What it was. The tool correlated the E1B data component alone, while the signal carries a data and a pilot component together. The pilot leaked into the data replica as a coherent interferer, riding on the sign of the navigation symbol times the pilot's secondary code. One number from the codes alone predicted the amplitude to within 1–11 %. Rebuilding the composite signal with no generator in the loop reproduced it exactly. Removing the pilot took it to zero.

    What changed. E1B is now correlated against a composite replica of both components, which removes 55–92 % of the split. The rest is stated as part of the instrument's error budget. L1 C/A has no pilot and remains the signal to measure with.

    5. A constant-Doppler model over a long capture¶

    What was seen. After a generator fix, a residual of about −2 cm remained against truth, first put down to the precision of the truth file.

    What it was. Refinement fits one Doppler to the whole series and corrects the code by its mean error. For a range acceleration a over a series of length T, that leaves −aT²/12 at the start epoch. On real satellites that is up to about 6 cm per 2 s capture, and different per satellite.

    What changed. The bias is identified, printed by the analysis probe, and stated in the user guide. Replacing the model is the next planned change, because it re-measures every store.

    What these cases changed¶

    • A result is screened against the instrument before it is attributed to a device. A ripple at one cycle per sample is equally the signature of a misplaced replica.
    • Controls use a different model from the thing they control. A control built by the same rule as the instrument cancels the instrument's error.
    • Retractions stay on the record. A finding that turned out to be about the instrument is worth more as a record than as a deletion.
    • Rates and slopes are measured, not assumed. Both the detector false-alarm rates and the discriminator gain were measured on the series themselves.
